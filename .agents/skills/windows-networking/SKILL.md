# Windows Networking

Trace adapter selection and command execution in `electron/network-doctor.cjs` and `electron/network.cjs`. Review argument validation and bounded execution at the IPC boundary. On a disposable Windows host record interface identity, effective route and DNS state before each reproduction. Check IPv4 and IPv6, VPN adapter transitions, and restoration after a controlled test.
